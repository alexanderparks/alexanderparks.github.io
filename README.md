# Portfolio Site (GitHub Pages)

This folder contains a one-page portfolio site:

- `index.html` — the whole site (HTML + CSS in one file)
- `resume.pdf` — downloadable resume
- `assets/` — put `headshot.jpg` here

## Quick setup
1. Create a GitHub repo (e.g., `alex-parks-portfolio`)
2. Upload these files to the repo root
3. Settings → Pages → **Deploy from a branch**
4. Branch: `main` • Folder: `/ (root)`
5. Your site will be at `https://<your-username>.github.io/<repo-name>/`

## Customize
- Update LinkedIn + GitHub links in `index.html`
- Add `assets/headshot.jpg` and uncomment the `<img>` tag
